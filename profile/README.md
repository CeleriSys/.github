## Sobre nosotros

Somos un equipo de desarrollo en Arequipa, Perú. Construimos aplicaciones
web, sistemas internos y automatizaciones para resolver problemas
de operación y gestión de información.

Esta organización reúne los repositorios de nuestros proyectos,
herramientas y experimentos.

## En qué trabajamos

- **Aplicaciones web:** interfaces, servicios y sistemas de gestión.
- **Automatización:** conexiones entre herramientas, datos y procesos.
- **Infraestructura:** servidores Linux, contenedores y despliegues.
- **IA aplicada:** asistentes, clasificación de documentos y análisis
  de información.

## Tecnologías

| Área | Herramientas |
| --- | --- |
| Frontend | Astro · React · Angular · TypeScript |
| Backend | Node.js · .NET |
| Infraestructura | Linux · VPS · Docker |
| Automatización y CI/CD | Google Apps Script · GitHub Actions |

El stack varía según los requisitos de cada proyecto.

## Colaboración

Consulta el README de cada repositorio para conocer su propósito,
configuración y estado.

En los proyectos abiertos a contribuciones, utiliza las issues
para reportar errores o proponer cambios. Cada repositorio define
sus propias condiciones de uso y licencia.
